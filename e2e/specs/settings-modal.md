# Settings Modal Interactions

## User can open settings from the toolbar

* Open "/"
* Open the settings dialog
* Page should contain "Settings"
* Page should contain "General"

## Environment provider is preconfigured

* Open "/"
* Open the settings dialog
* Page should contain "environment"
* Page should contain "Add Provider"

## Settings sections are navigable

* Open "/"
* Open the settings dialog
* Page should contain "General"
* Page should contain "Personalization"
* Page should contain "About"

## Image provider key fields exist

* Open "/"
* Open the settings dialog
* Page should contain "AIza"
* Page should contain "Access key"

## Closing the settings dialog

* Open "/"
* Open the settings dialog
* Page should contain "Reset to Factory Settings"
* Click the "Close" button
* Page should not contain "Reset to Factory Settings"

## Factory reset control is available

* Open "/"
* Open the settings dialog
* Page should contain "Reset to Factory Settings"
* Click the "Close" button
