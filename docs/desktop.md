# Desktop app

Calca also ships as a signed desktop app (built with Electrobun) for macOS and
Windows. Same canvas, same BYOK settings — plus a native shell, native menus,
and auto-updates.

## Install

Download the latest build from
[GitHub Releases](https://github.com/espetro/calca/releases):

- **macOS:** `stable-macos-arm64-Calca.dmg`
- **Windows:** `stable-win-x64-Calca-Setup.zip`

Direct links are also on the [landing page](https://calca.illo.fyi) under
"or download for".

## Notes

- Settings and boards are stored locally; the web and desktop apps are
  independent installs — export/import a board file to move work between them.
- The desktop app auto-updates on release channels.
- Right-click on the canvas opens a native context menu (select-all-aware
  copy/paste, frame counts).
