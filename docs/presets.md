# Formats & presets

Calca is not a web-design-only tool — each frame is generated HTML/CSS sized for
a format, so the same canvas holds app UIs, marketing pages, brand cards, deck
slides, and emails side by side.

## System prompt presets

The preset controls the design language Calca writes for. Pick one in
**Settings → System prompt**, or deep-link with `?preset=`.

| Preset (`?preset=`) | Optimized for | Examples |
| --- | --- | --- |
| `uiux` | App and product interfaces | Dashboards, settings panels, mobile flows |
| `marketing` | Marketing sites and landing pages | Hero sections, pricing pages, feature grids |
| `brand` | Identity and launch assets | Announcement cards, social posts, brand boards |
| `presentation` | Deck slides | Cover slides, stat layouts, agenda pages |
| `email` | Email/newsletter HTML | Product announcements, digests, invites |
| `custom` | Your own system prompt | Anything else — write it yourself |

## Sample prompts to steal

- **App UI** — `A fleet-tracking dashboard with a dark sidebar, four KPI cards,
  a route-status table, and a small map panel.`
- **Brand card** — `A 1200x628 launch announcement card for a minimal
  note-taking app called Jot — bold headline, one screenshot mockup, release
  date.`
- **Deck slide** — `A pitch-deck cover slide for a warehouse-robotics startup —
  big title, one-line thesis, team row, and a contact footer.`
- **Web page** — `A landing page for a sourdough bakery — warm hero with a
  tagline, a three-item bread menu with prices, a short story section, and a
  footer with hours and address.`

::: callout tip
Prompts that name the components ("dark sidebar, four KPI cards, a route-status
table") get far better layouts than vague ones ("a cool dashboard").
:::
