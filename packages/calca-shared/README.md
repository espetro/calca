# @calca/shared

Shared TypeScript types for the Calca stack — canvas (`Point`, `ToolMode`), comments, design documents (`DesignIteration`, `GenerationGroup`, `CanvasImage`), and generation-pipeline status (`PipelineStage`, `PipelineStatus`). Types only; consumed by `@calca/canvas-*`, `@calca/mcp-*`, and the Calca app.
